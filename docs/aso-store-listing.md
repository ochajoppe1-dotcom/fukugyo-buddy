## 詳しい説明（4000文字以内）

```
■ 副業バディAIとは

副業バディAIは、「副業診断」と「副業伴走型AI」の2つでできた情報提供アプリです。

・副業診断　　　15の質問で、あなたに向いている副業のタイプがわかります
・副業伴走型AI　始めたあとの迷いに答え、記録をもとに続け方を一緒に考えます

あわせて、購入を迷っている情報商材の販売ページを27項目でチェックする機能もあります。
始める前の判断から、続けるための記録・相談まで、副業のひととおりを1つにまとめました。

■ 無料でできること（登録のみ・課金なし）

◆ LP診断（セルフチェック版）
副業教材・情報商材の販売ページを27項目でチェック。煽り表現・販売者情報・価格・手法の観点から危険度をスコア表示。購入前の冷静な判断材料になります。

◆ 適性診断（パターン判定版）
15の質問に答えるだけで、あなたに向いた副業タイプを判定。向いてる副業・避けたい副業・始め方のアドバイスがわかります。

◆ 詐欺アラート
情報商材詐欺、SNS勧誘、面談営業など、副業詐欺の典型的な手口を業界全体の傾向としてまとめて配信。被害を未然に防ぎます。

■ こんな方におすすめ

・副業を始めたいけど何から手をつけていいかわからない
・情報商材・副業教材を買おうか迷っている
・副業詐欺に遭わないか不安
・自分に合った副業を知りたい
・副業を始めたけど続けられるか心配

■ さらに使える有料プラン（任意）

より詳しいAI診断・AI相談・副業日記・数字レポートなどは、Webサイトのプランでご利用いただけます。
```

## ASO運用のコツ（公開後）

1. **レビュー・評価を集める**：初期は知人に頼んで★4〜5を数件
2. **定期的に説明文を更新**：反応の良いキーワードに寄せる
3. **インストール数 × 維持率**がランキングに影響 → 使い続けてもらう工夫
4. **更新頻度**：アプリを定期更新するとストア評価が上がる（WebView方式なら中身更新は自動反映だが、たまにアプリverも上げる）
